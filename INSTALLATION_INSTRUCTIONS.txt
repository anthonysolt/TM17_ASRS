INSTALLATION INSTRUCTIONS - TM17_ASRS

macOS (Using Homebrew)
------------------
All commands are denoted with a '#' symbol, these commands should be ran in the terminal of your machine
 
0) Install the zip fie for the code from the github repository.

1) Open your terminal and install Homebrew:
#   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2) Install Node.js and PostgreSQL. Activate Postgres:
#   brew update
#   brew install node postgresql
#   brew services start postgresql

3) Open new terminal window and verify your installations. This should return the version number of the appliations you installed. Close this newly made terminal. 
#   psql --version
#   node --version

4) Create role and database instance for the application (run as a postgres superuser):
#   psql postgres -c "CREATE ROLE asrs WITH LOGIN PASSWORD 'change-me';"
#   psql postgres -c "CREATE DATABASE asrs OWNER asrs;"

5) Navigate to the directory where the applications code is stored (TM17 folder), execute the following command to load the most recent content from the DB
#   pg_restore --dbname=postgresql://asrs:change-me@localhost:5432/asrs /database/local_snapshot.dump --no-owner --no-acl

7) Open a new  terminal window, navigate to the TM17 folder. Install dependencies and run the app:
npm install
npm run dev

8) Once the application is running, open your browser and go to localhost.com:3000/  to use the application

Windows (winget)
------------------
All commands are denoted with a '#' symbol, these commands should be ran in the powershell terminal of your machine
When running powershell, please run it as Administrator for installs and service control.

0) Install the zip fie for the code from the github repository.

1) Install Node.js and PostgreSQL with winget:
#   winget install --id OpenJS.NodeJS -e
#   winget install --id PostgreSQL.PostgreSQL -e

2) Start PostgreSQL service (service name may vary):
#   net start postgresql-x64-15

3) Open a seperate powershell window, Verify installations in PowerShell. This should give you a version number of the appliations you installed:
#   psql --version
#   node --version

4) Create role and database (run as postgres user):
#   psql -U postgres -c "CREATE ROLE asrs WITH LOGIN PASSWORD 'change-me';"
#   psql -U postgres -c "CREATE DATABASE asrs OWNER asrs;"

5) Navigate to the TM17 folder that you installed, Execute the following command to load the latest DB data. 
#   pg_restore --dbname=postgresql://asrs:change-me@localhost:5432/asrs .\database\local_snapshot.dump --no-owner --no-acl


7) Open a seperate powershell window and navigate to the TM17 folder. Install dependencies and run app:
#   npm install
#   npm run dev

8) Once the application is running, open your browser and go to localhost.com:3000/  to use the application

Notes & Troubleshooting
- The repo uses `DATABASE_URL` in `.env.local` (example: DATABASE_URL=postgresql://asrs:change-me@localhost:5432/asrs).
- Use `pg_restore` when you have a custom-format dump (`.dump` or `.dump` created with `pg_dump --format=custom`).
- If `pg_restore` fails on permissions, restore as a superuser and then change ownership, or ensure `asrs` role exists.
- On Windows, winget package ids and service names can differ; run `winget search postgresql` and check Services.

Paths referenced in this guide (relative to repo root):
- .env.local
- database/local_snapshot.dump
